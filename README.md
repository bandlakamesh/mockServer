# Mock Server

This repository contains a mock server that simulates API responses for testing purposes.

## Features
- Simulate various API endpoints
- Customize responses based on request parameters
- Easy to set up and use

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/bandlakamesh/mockServer.git
   ```
2. Navigate to the project directory:
   ```bash
   cd mockServer
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## Usage
To start the mock server, run:
```bash
npm start
```
